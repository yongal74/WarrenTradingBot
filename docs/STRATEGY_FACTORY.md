# Warren Strategy Factory — 투자전략 완전 정리

## 핵심 전략: FVG+OB (Fair Value Gap + Order Block)

### 개념
ICT(Inner Circle Trader) 기반 스마트머니 전략.
기관이 대량 매매한 흔적(Order Block)과 가격 불균형 구간(FVG)으로
되돌림 진입 타이밍을 포착.

### FVG (Fair Value Gap) 감지
```
봉 i-2의 High < 봉 i의 Low  →  상승 FVG (불균형 상승)
갭 크기 > 0.05% 이상만 유효
```

### Order Block (OB) 감지
```
봉 i: 음봉 (Close < Open)
봉 i+1~i+2: 상승 임펄스 > 0.3%
→ 봉 i 전체가 Order Block (기관 매수 구간)
```

### 진입 조건
```
1. 가격이 FVG/OB 구간에 되돌아옴 (Low <= zone_high AND Close >= zone_low)
2. SL = zone_low (구간 아래)
3. TP = entry + SL거리 × 2.0 (R:R = 2:1)
4. SL 범위: 0.1% ~ 1.5% (과도한 SL 제외)
5. 유효기간: 20봉 이내
```

### 파라미터
| 파라미터 | 값 | 설명 |
|---------|-----|------|
| RR_RATIO | 2.0 | 리스크:리워드 비율 |
| MAX_SL_PCT | 1.5% | 최대 손절 범위 |
| MIN_SL_PCT | 0.1% | 최소 손절 범위 |
| ZONE_EXPIRE | 20봉 | 구간 유효기간 |

```
1. Q6~7점: 무조건 포함 (최우선)

3. 최소 5건 / 최대 10건 (Flexible)
4. 시간대: KST 9~11시 / 22~24시만
```

### 랭킹 점수 산식
```
rank = quality_score × 2.0
     + (4H 타임프레임이면 +5.0)
     + (CRYPTO 시장이면 +2.0)
     + min(구간크기% × 5, 3.0)
```
