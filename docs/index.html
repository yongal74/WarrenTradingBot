FVG+OB 핵심 전략

25개 전략 엔진

EMA 크로스, SuperTrend, MACD, RSI, Bollinger Band, Ichimoku, CHoCH 등 전략 자동 신호 생성.

🌟

C1~C5 합류점

5개 합류점 모델로 전략 신호를 결합해 고확률 진입 타이밍 포착.

🌐

3개 시장 동시 운용

한국주식(KIS), 미국주식, 업비트 암호화폐를 하나의 대시보드에서 관리.

📄

Streamlit 대시보드

Overview, 신호 스캐너, Strategy Factory, 백테스트, 트레이드 로그 등 8개 페이지.

🔔

TradingView 웹훅

TradingView 알림 → FastAPI 웹훅 → 자동 주문 파이프라인.

📅

일일 자동 스캔

Windows Task Scheduler로 KR(09:00) / US(22:30) 매일 자동 포워드 스캔.

🛡

리스크 관리

트레이드당 최대 1% 리스크, SL/TP 자동 설정, 일일 손실 한도 초과 시 자동 중단.

🚀

원클릭 실행

WARREN_START.bat 더블클릭 한 번으로 대시보드 + 웹훅 + 스캐너 동시 시작.

설치 방법
Python 환경에서 4단계로 바로 실행
1

다운로드 & 압축 해제

아래 다운로드 버튼에서 ZIP 파일을 받아 원하는 폴더에 압축 해제합니다.

2

패키지 자동 설치

install.bat을 더블클릭하면 필요한 Python 패키지가 자동으로 설치됩니다.
(Python 3.9+ 필요 — python.org에서 설치)

3

API 키 설정

.env.example을 .env로 복사하고 KIS / 업비트 API 키를 입력합니다.
KIS 모의투자: apiportal.koreainvestment.com

4

실행!

WARREN_START.bat을 더블클릭하면 대시보드가 자동으로 브라우저에서 열립니다.
(http://localhost:8501)
