## 5. 매일 복기 루틴 (자동화)

```
09:05  한국장 스캔    → BB반등/MACD/SuperTrend 신호 스캔 → 텔레그램 알림
10:00  중반 스캔      → 추가 신호 확인
13:00  오후 스캔      → 오후 신호 확인
15:20  장 마감 전     → 포지션 청산 확인 → 텔레그램 알림
06:05  복기 + 학습   → 필터 발굴 + 5-Pillar 손실 방어 검증 → 텔레그램 리포트
22:35  미국장 스캔    → BB반등/Momentum 신호 스캔 → 텔레그램 알림
매 4H  CRYPTO 스캔   → FVG+OB 4H 봉 마감시 자동 스캔
```

### 학습 에이전트 동작

1. **필터 중요도 분석**: 필터 존재시 vs 부재시 승률 비교 → 중요도 ★★★/★★/★
2. **Fake 신호 패턴 추출**: 시간대, 볼륨, 구조 기반 Fake 공통점 발굴
3. **자동 파라미터 조정**: 데이터 30건+ 시
   - 승률 차이 20%p+ → required_filter 강제 지정
   - 승률 < 45% → 품질 기준 +1 상향
   - 승률 > 70% → 일일 한도 +2 확대
4. **전략 파라미터 버전 관리**: `strategy_params.json` 모든 변경 이력 보존
5. **5-Pillar 손실 방어 검증**: Pillar1/Pillar4 가 적용됐다면 차단됐을지 계산 → 리포트

## 9. 로컬 앱 실행 방법

### 매일 실행
```
WARREN_START.bat  ← 더블클릭
  → 매크로 국면 체크 (Pillar 1)
  → BB반등 + FVG+OB 즉시 스캔
  → 대시보드 시작 (http://localhost:8505)
  → 브라우저 자동 오픈
```

### 자동화 등록 (Windows Task Scheduler)
```
setup_scheduler.bat  ← 우클릭 → 관리자로 실행
  → Warren_Scanner_KR_09   09:05 등록 (한국장 오전)
  → Warren_Scanner_KR_10   10:00 등록 (한국장 중반)
  → Warren_Scanner_KR_13   13:00 등록 (한국장 오후)
  → Warren_Scanner_US      22:35 등록 (미국장)
  → Warren_Learning        06:05 등록 (복기/학습)
  → Warren_Scanner_15m     매 15분 상시 스캔
```

### 수동 실행
```bash
# 즉시 스캔 (BB반등 + FVG+OB)

# 복기 + 학습 (필터 발굴 엔진)
```
