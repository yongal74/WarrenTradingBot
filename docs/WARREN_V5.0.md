## 3. v5.0 핵심 신규 기능

### 3-1. Circuit Breaker (서킷브레이커)

```python
# _check_circuit_breaker(portfolio) → (halted: bool, reason: str)

# 일일 손실 -1.5% 초과 → 당일 신규 진입 전면 차단
daily_pnl_pct <= DAILY_LOSS_LIMIT (-0.015)

# MDD -10% 초과 → 봇 자동 정지 (신규 진입 차단)
total_pnl_pct <= MDD_LIMIT (-0.10)
```

- run_once() 진입 직전 매 15분 체크
- 일별 손익은 paper_trades.csv에서 실시간 집계 (정확도 최우선)
- Circuit Breaker 발동 시 포지션 점검(SL/TP)은 계속 진행, 신규 진입만 차단

### 3-2. 섹터 집중도 관리

```
SECTOR_MAP (KR/US 섹터 분류):
  KR: 반도체(5종목) / 방산(3종목) / 바이오 / 통신 / IT / 생활 / 자동차 / 조선 / 금융 / 에너지
  US: 반도체US(5종목) / 빅테크(2종목) / 이커머스 / 크립토자산 / 전기차
  CRYPTO: BTC / ETH / SOL / XRP (각자 독립 섹터 — 집중도 제한 없음)

MAX_SECTOR_POSITIONS = 2
  → 같은 섹터 종목이 이미 2개 오픈이면 추가 진입 차단
```

**반도체 섹터 예시:**
- 삼성전자(005930) + SK하이닉스(000660) = 2개 → 삼성전기(009150) 진입 차단
- NVDA + AMD = 2개 → AVGO 진입 차단

### 3-3. 포트폴리오 메트릭 자동 계산

매 저장(`_save_portfolio`) 시 paper_trades.csv 전체에서 집계:

| 메트릭 | 계산식 | 의미 |
|--------|--------|------|
| **Sharpe Ratio** | avg(PnL) / std(PnL) | 리스크 대비 수익 (>1 양호) |
| **Profit Factor** | 총이익 / 총손실 | 1이상이면 흑자 (>1.5 양호) |
| **Expectancy** | WR×평균이익 - LR×평균손실 | 거래당 기대 수익 (원) |
| **avg_win_krw** | 평균 승리 거래 손익 | |
| **avg_loss_krw** | 평균 패배 거래 손실 | |

paper_portfolio.json의 `"metrics"` 키에 자동 저장.

## 5. 리스크 관리 (v5.0 강화)

```
트레이드당 포지션: KR 500만원 / US 1,000만원 / CRYPTO 500만원
최대 포지션: 시장별 5개 동시 (전체 최대 15포지션)
동일 섹터: 최대 2포지션 (V5.0 신규)

일일 손실 한도: -1.5% → 당일 신규 진입 차단 (V5.0: -6%에서 강화)
주간 손실 한도: -5%
MDD 한도: -10% → 봇 자동 정지 (V5.0: -20%에서 강화)

일중 거래 한도: 시장별 최대 10건/일
오버나이트: KR 금지 (MAX_HOLD 초과 시 강제청산)
           US/CRYPTO 허용 (4H = 최대 15일, 15m = 최대 8시간)
```

## 6. 전략 구조 (v4.6 유지)

### 시장별 전략

| 시장 | 메인전략 | TF | 보조(15m) | R:R | 수수료 |
|------|---------|-----|---------|-----|--------|
| KR | 종목별 확정전략 (레지스트리) | 일봉/15m | 3종 필터 | 1:2 | 0.23% |
| US | 종목별 확정전략 (레지스트리) | 일봉/15m | 3종 필터 | 1:2 | 0.25% |
| CRYPTO | FVG + OB | 4H | - | 1:3 | 0.10% |

### 15m 보조지표 3종 필터 (2개 이상 충족 시 진입)

```
① EMA_Align   — 15m EMA 정배열 (단기>중기>장기)
② CHoCH       — 구조전환 (Change of Character) 확인
③ SL정밀화    — SL pct ≤ -1.5% 이내
```

### TP1→TP2→TP3 트레일링 청산

```
진입(entry)
  └─ TP1 = entry + R          ← 초기 목표
       └─ TP2 = entry + 2R    ← 4/6점 이상 시 연장, SL → TP1
            └─ TP3 = entry + 3R  ← 5/6점 이상 시 연장, SL → TP2
                 └─ 항상 청산
```

## 7. 8중 방어선 (v5.0: 7중 → 8중)

```
Layer 1: 하드 화이트리스트 (_HARD_WL)
         → 유니버스 외 종목 영구 차단

Layer 2: Quality Score 필터 (Q4 이상)
         → 이중방어: scan_all + open_positions

Layer 3: open_ticker_tf 집합
         → 동일 ticker+timeframe 중복 포지션 완전 차단

Layer 4: closed_today 전 타임프레임 차단
         → 당일 청산 종목 재진입 차단

Layer 5: tf_cooldowns
         → 4H = 4시간, daily = 24시간 쿨다운

Layer 6: MAX_POS_PER_MARKET = 5
         → 시장별 최대 동시 포지션 수 제한

Layer 7: MAX_DAILY_TRADES = 10
         → 시장별 하루 최대 거래 건수 제한

Layer 8 (V5.0 신규): 섹터 집중도
         → 동일 섹터 최대 2포지션 동시 보유
```

## 9. 실행 구조

```
paper_trade_scan.bat
  └─ run_master_loop.py (15분 스케줄)
       └─ run_paper_trading.py
            ├─ _check_circuit_breaker()   ← V5.0 신규
            ├─ check_positions()           ← SL/TP/CHoCH 체크
            ├─ open_positions()            ← 8중 방어선 + 섹터 체크
            └─ _save_portfolio()           ← 메트릭 자동 갱신
```

### 주요 파일

```
run_paper_trading.py          ← 페이퍼 트레이딩 메인 (v5.0 핵심 수정)
config/settings.py            ← 리스크 한도 (v5.0 강화)
version.py                    ← 버전 정보 (5.0.0)
logs/paper_portfolio.json     ← 포트폴리오 + 메트릭 현황
logs/paper_positions.json     ← 오픈 포지션
logs/paper_trades.csv         ← 청산 거래 기록
docs/WARREN_V5.0.md           ← 이 문서
docs/WARREN_V4.6.md           ← v4.6 문서 (참고용)
```
