### 시장별 전략

### 15m 보조지표 3가지 활용법 (v4.5 핵심 추가)

```
1H 메인 신호 발생 시 15m으로 필터링:

① 진입 타이밍 정밀화
   → 1H 신호 후 15m 반전 캔들 확인 후 진입
   → 불필요한 조기진입 방지

② RSI 과매도 동시 확인
   → 1H 신호 + 15m RSI < 35 동시 충족
   → 과매수 구간 진입 방지

③ 볼륨 급등 확인
   → 15m 볼륨 2배↑ 확인 후 진입
   → 허수 신호 필터링

→ 3가지 중 2개 이상 충족 시만 진입 → 승률 상승
```

## 4. 5-Pillar 구조

```
Pillar 1: 거시국면 (VIX/DXY/환율) → HALT/DEFENSIVE/NORMAL/AGGRESSIVE
Pillar 2: 종목 스크리닝 (30종목 고정)
Pillar 3: BB반등+Momentum (KR/US) / FVG+OB (CRYPTO)
Pillar 4: 15m 보조지표 3종 품질 필터
Pillar 5: 게이트키퍼 (일 손실 -6% → 차단, MDD -20% → 정지)
```

### 국면별 행동

| 국면 | VIX | 행동 |
|------|-----|------|
| HALT | >35 | 전면 차단 |
| DEFENSIVE | >25 | 15m 필터 3개 모두 충족 시만 진입 |
| NORMAL | 20~25 | 15m 필터 2개 이상 충족 시 진입 |
| AGGRESSIVE | <20 | 15m 필터 1개 이상 충족 시 진입 |
